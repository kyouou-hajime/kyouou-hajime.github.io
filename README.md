# 饗応 元 公式サイト

京都・丸太町「饗応 元（きょうおう はじめ／KYOUOU HAJIME）」の公式サイトです。

公開URL: https://kyouou-hajime.github.io/

## 店舗情報の基準

- 通常18:00開店。予約なしの最終入店は23:00
- 23:00までの電話予約等で、予約・営業状況に応じてアラカルトは最長翌02:00まで対応
- ノーゲストの場合は23:00閉店。深夜の飛び込み来店は案内しない
- 日曜日は原則休業。店主が日付を指定した日のみ営業し、最新の確定カレンダーを優先
- 2026年11月の指定日曜営業：11/15（予約あり）、11/22（祝前日）、11/29（肉会）
- 2026年11月23日（月・祝）は2日前までに予約がある場合に営業
- 水曜ランチ・最終日曜の昼飲みは休止
- 当日の電話予約: 23:00まで
- アラカルト: お席のみの予約も可能
- コース: 来店日の2日前までに予約
- 電話: 075-600-0511

店舗情報を変更するときは、`index.html`、`access.html`、`faq.html`、各ページのフッター、`llms.txt`、構造化データを同時に更新してください。Googleビジネスプロフィールなど外部サービスは、個別の更新許可・管理権限を確認し、申請・保存・実際の公開反映を区別して履歴へ残します。日付別営業は `news.html#business-hours-2026-11` と最新の店主指示を確認し、月替わりに古い特別営業日を流用しないでください。

## 主なファイル

- `index.html`: トップページ
- `menu.html`: 料理・酒
- `nikukai.html`: 毎月29日の肉会
- `sakasho.html`: 酒匠の説明
- `about.html`: 店主・店のこだわり
- `access.html`: 予約・営業時間・アクセス
- `faq.html`: よくある質問
- `news.html`: お知らせ
- `blog.html`: 読みもの一覧
- `css/style.css`: 全ページ共通デザイン
- `css/home.css`: トップページ専用デザイン
- `js/main.js`: モバイルナビゲーション
- `sitemap.xml` / `robots.txt`: 検索エンジン向け設定

## 公開方法

`main` ブランチへの反映後、GitHub Pagesが自動で公開します。公開後はトップ、予約リンク、電話リンク、地図、スマートフォン表示を確認してください。
