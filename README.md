# 饗応 元 公式サイト

京都・丸太町「饗応 元（キョウオウハジメ）」の公式サイトです。

公開URL: https://kyouou-hajime.github.io/

## 店舗情報の基準

- 営業時間: 17:00〜翌2:00
- 最終入店: 24:00
- 定休日: 不定休
- 当日の電話予約: 23:00まで
- アラカルト: お席のみの予約も可能
- コース: 来店日の2日前までに予約
- 電話: 075-600-0511

店舗情報を変更するときは、`index.html`、`access.html`、`faq.html`、各ページのフッター、`llms.txt`、構造化データを同時に更新してください。Googleビジネスプロフィールなど外部サービスの表記も同じ内容に揃えます。

## 主なファイル

- `index.html`: トップページ
- `menu.html`: 料理・酒
- `nikukai.html`: 毎月29日の肉会
- `sakasho.html`: 酒匠の説明
- `about.html`: 店主・店のこだわり
- `access.html`: 予約・営業時間・アクセス
- `faq.html`: よくある質問
- `news.html`: お知らせ
- `blog.html`: 読みもの一覧
- `css/style.css`: 全ページ共通デザイン
- `css/home.css`: トップページ専用デザイン
- `js/main.js`: モバイルナビゲーション
- `sitemap.xml` / `robots.txt`: 検索エンジン向け設定

## 公開方法

`main` ブランチへの反映後、GitHub Pagesが自動で公開します。公開後はトップ、予約リンク、電話リンク、地図、スマートフォン表示を確認してください。
